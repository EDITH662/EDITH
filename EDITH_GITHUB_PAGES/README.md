# EDITH — GitHub Pages

Página promocional estática de EDITH, lista para publicarse con GitHub Pages.

## Publicación

1. Crea un repositorio en GitHub.
2. Sube **todos los archivos de esta carpeta a la raíz** del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub publique el sitio.

El archivo `index.html` está en la raíz y el botón de descarga apunta a `EDITH.zip`.
